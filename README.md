# PPIO CALENDAR

Google Calendar와 읽기 전용 iCal 캘린더를 한눈에 보는 Windows 데스크톱 달력 앱입니다.

## 다운로드

- [최신 Windows 설치본](https://github.com/ppiohouse/ppio-calendar/releases/latest)
- Windows 10/11, x64 및 32비트(ia32) 지원

> 현재 설치 파일에는 코드 서명이 없습니다. Windows SmartScreen 안내가 나타날 수 있으므로 이 저장소의 공식 릴리스와 `SHA256SUMS.txt`를 확인해 주세요.

## 주요 기능

- 월간 달력과 날짜별 일정 목록
- Google 계정 연결 후 선택한 캘린더의 일정 읽기·추가·수정·삭제
- Google Calendar에 저장된 반복 일정 표시
- 비밀주소(iCal/ICS) 캘린더 읽기 전용 연결
- 일정 시작 전 Windows 알림
- 오프라인 캐시와 수동 새로고침
- 항상 위, 가장자리 붙이기, 창 크기 조절
- 한국어를 포함한 13개 언어
- 새 버전 자동 확인 및 아키텍처별 공식 설치 파일 바로 받기

## Google 연동과 개인정보

PPIO CALENDAR는 사용자가 선택한 Google Calendar 일정과 캘린더 목록만 Google API에서 직접 읽고 씁니다. 일정 데이터와 로그인 토큰은 PPIO.HOUSE 서버를 거치지 않으며, 토큰은 Windows의 암호화 저장소로 보호합니다.

자세한 내용은 [개인정보처리방침](PRIVACY.md)을 확인해 주세요.
