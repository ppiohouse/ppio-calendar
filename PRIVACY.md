# PPIO CALENDAR 개인정보처리방침 / Privacy Policy

시행일 / Effective date: 2026-09-30

## 한국어

PPIO CALENDAR는 사용자가 선택적으로 Google 계정을 연결할 때 다음 Google Calendar 권한과 데이터를 사용합니다.

- Google Calendar 일정 권한(`calendar.events`): 사용자가 선택한 캘린더의 일정을 읽고, 사용자가 앱에서 요청한 일정 추가·수정·삭제를 Google Calendar에 반영하는 용도
- Google Calendar 목록 읽기 권한(`calendar.calendarlist.readonly`): 캘린더 이름, 색상, 접근 권한 등 사용자가 표시할 캘린더를 고르는 데 필요한 목록 정보를 읽는 용도

캘린더 목록과 일정은 사용자의 기기와 Google Calendar 사이에서 직접 전송되며 PPIO.HOUSE 서버로 전송되지 않습니다. PPIO CALENDAR는 Google 사용자 데이터를 광고, 분석 또는 사용자 추적에 이용하지 않으며 제3자에게 판매하거나 공유하지 않습니다. PPIO CALENDAR의 Google API 정보 이용 및 전송은 제한적 사용 요건을 포함한 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)을 준수합니다.

OAuth 로그인 토큰은 Windows가 제공하는 암호화 저장소를 통해 로컬 기기에 보관합니다. 선택한 캘린더의 일정 일부는 빠른 표시와 일시적인 오프라인 사용을 위해 로컬 기기에 캐시될 수 있습니다. 앱에서 Google 연결을 해제하면 로컬 토큰과 Google 일정 캐시를 삭제하고 Google에 권한 취소를 요청합니다.

사용자가 직접 추가한 iCal/ICS 비밀주소와 해당 캘린더의 캐시는 로컬 기기에만 저장되며 PPIO.HOUSE 서버로 전송되지 않습니다. 비밀주소에는 캘린더 접근 권한이 포함될 수 있으므로 다른 사람과 공유하지 않아야 합니다.

## English

PPIO CALENDAR uses the following Google Calendar permissions and data only when a user chooses to connect a Google account:

- Google Calendar events permission (`calendar.events`): to read events from calendars selected by the user and to apply event creations, edits, or deletions the user requests in the app
- Google Calendar list read-only permission (`calendar.calendarlist.readonly`): to read calendar-list information such as names, colors, and access roles so the user can choose which calendars to display

Calendar lists and events are transferred directly between the user's device and Google Calendar. They are not sent to a PPIO.HOUSE server. Google user data is not used for advertising, analytics, or tracking and is not sold or shared with third parties. PPIO CALENDAR's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

OAuth tokens are stored locally using encrypted storage provided by Windows. Some events from selected calendars may be cached locally for faster display and temporary offline use. Disconnecting Google in the app removes the local token and Google-event cache and requests revocation from Google.

Any secret iCal/ICS URL added by the user and its calendar cache remain on the local device and are not sent to a PPIO.HOUSE server. A secret calendar URL may grant access to the calendar and should not be shared with others.
